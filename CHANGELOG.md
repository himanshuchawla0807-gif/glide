
## Windows 0.1.0 preview

- Rust/Tauri Windows x64 launcher with Shift+Space, a resident tray menu and explicit Chrome-profile pairing.
- Six themes, anchored suggestion dropdown, animated orb and reduced-motion support.
- Shared Chrome companion with optional Google/history suggestions; authenticated named pipe and per-user native host registration.
- Per-user install/uninstall scripts, Windows CI and setup documentation. Unsigned preview; interactive Windows validation remains necessary.
